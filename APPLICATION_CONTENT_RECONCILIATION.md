# Tenno-Hub Application Content Reconciliation

The initial reconciliation was reviewed against the WARFRAME Wiki and official PC patch index on **November 10, 2026**. The Prologue to Tau quest pages and current chapter list were rechecked in the in-app browser on **November 17, 2026**; no CAPTCHA or interactive access restriction appeared.

> **November 17 prerequisite-scope follow-up:** The registry was narrowed from 227 to 163 entries by iteratively removing 64 non-quest entries that had no remaining downstream content. The checklist retains quests with no dependents, plus non-quest gates that lead to tracked quests, systems, source routes, milestones, or Star Chart regions. Amp parts tiers, Nautilus access, and Necramech Railjack Deployment Access are no longer checklist entries because no remaining tracked content depends on them. The audit now enforces the no-non-quest-leaf rule. A later quest integration adds Eris Mortem, bringing the current total to 164. See the current [prerequisite audit](./PREREQUISITE_AUDIT.md) and [generated inventory](./PREREQUISITE_AUDIT_INVENTORY.md).

> **November 17 Eris Mortem correction:** The prior functional quest list ended at Vessel and omitted Eris Mortem. A manually added registry record was not enough: it lacked a defined prerequisite ID and Handbook/test/milestone integration. Eris Mortem is now a canonical quest completion entry, its own final Prologue to Tau chapter, with Vessel as its direct prerequisite. It is included in the current quest inventory and Tau milestone. It is not gated on Operation: Taubound.

## Coverage baseline

Before the quest reconciliation, the Handbook's independent quest array contained **41 entries** and ended with **The Old Peace** (Update 41, December 10, 2025). That was the Handbook's visible-content cutoff, not the prerequisite registry's cutoff. The registry already had Jade Shadows: Constellations, but the Handbook did not. It represented Prologue to Tau as one internal “Tau Prologue Quest Series” completion gate, so Lua and Vessel had no distinct Handbook or completion identities. The Handbook also treated Prelude to War as one quest instead of listing its three playable chapters. After adding the first two released Tau chapter IDs, the tracked individual-chapter cutoff was Vessel, introduced in Hotfix 44.1.2 on October 15, 2026; the earlier entry for Eris Mortem was incomplete and did not compile or appear in quest-facing features.

The current Wiki quest inventory has **48 entries**: 30 Main Quests, 6 Side Quests, and 12 Warframe Quests. The independent expected inventory is maintained in [`wikiQuestInventory.fixture.ts`](src/catalog/quests/__tests__/wikiQuestInventory.fixture.ts). The Eris Mortem page identifies it as a replayable Main Quest, the final part of Prologue to Tau, introduced in Hotfix 44.1.4.1 on October 28, 2026; Vessel is its direct requirement. Epoch Operation: Taubound is temporary and does not unlock persistent progression; it is not represented in the prerequisite graph or Handbook quest inventory.

The official PC patch index currently ends at **Iceblade of Narin: The Icebind Hotfix 44.1.4.1, October 28, 2026**. Recent progression releases checked were Updates 42, 43, 43.5, 44, 44.1, Hotfix 44.1.2, and subsequent hotfixes through 44.1.4.1. The earlier reconciliation incorrectly treated 44.1.4.1 as having no new quest; the current Wiki quest page identifies Eris Mortem as introduced in that hotfix. The official DE forum post documents the hotfix but mentions Eris only in a fix for event-alert visibility, not as a quest unlock source. The WFCD item, drop, and Public Export Plus snapshots in the repository were synced on November 8, after that latest release.

## Implemented corrections

- Added distinct, persistent completion IDs for **Lua**, **Vessel**, and **Eris Mortem**. Lua directly requires both The Hex and The Old Peace; Vessel directly requires Lua; Eris Mortem directly requires Vessel. The old series ID remains as a migration alias only.
- Added **A Man of Few Words** to the prerequisite registry with its actual access requirement: access to any Relay to speak with Darvo. It has no preceding quest gate.
- Kept **Jade Shadows: Constellations**' direct Jade Shadows requirement and made it visible in the Handbook's Main Quests category.
- Added the missing Mainline milestone for Jade Shadows: Constellations and updated the Tau milestone to require all three released chapters.
- Changed the UI display name for the Hex epilogue to **Finale**, matching the current Wiki section and quest index; kept its established completion ID and recorded that it is part of The Hex.
- Corrected visible canonical names to **Awakening** and **The Maker**. The Prelude to War group is presentation only; Chimera Prologue, Erra, and The Maker remain separate trackable quests.
- Migrated a saved `quest_tau_prologue_series: true` value to the two chapter IDs that existed when that legacy key was in use. Explicit per-chapter values take precedence, the retired alias is removed, and the migration deliberately leaves Eris Mortem incomplete unless the player has an explicit completion value; this prevents an older “series complete” flag from falsely completing a quest released later.
- Changed the Handbook quest list into a projection of the shared registry. New registered quests are included automatically; tests require Handbook, registry, and an independent Wiki fixture to agree in both directions.

## Validation and sources

The current prerequisite audit reports **162 registry entries, 179 direct required edges, 18 alternative references, 25 typed conditions, 47 milestone rollups, 16,256 source entries, 514 Star Chart nodes, and 13 Junctions**. It reports no non-quest leaf entries, duplicate IDs or labels, dangling references, invalid conditions, cycles, redundant direct edges, invalid chart relationships, external-consumer errors, or missing hard-gate evidence.

The independent quest reconciliation now verifies all **48** Wiki-index entries against the registry, Handbook projection, and server-rendered Handbook quest-name order. On the current `origin/main` base, `npm test` passed **789 tests across 53 files**; `npm run build`, `npm run validate:sources`, the prerequisite audit, focused ESLint for the touched TypeScript files, and `git -c core.whitespace=cr-at-eol diff --check` all passed. Vite emitted its existing large-chunk warning. The prior full-repository ESLint baseline was 1,870 errors and 37 warnings; whole-repository lint was not run for this quest integration.

The raw external-data validator is not clean: **21 of 23** drop-data files pass; `all.slim.json` has 13 upstream `NaN` chance values and `relics.json` has one record with an undefined relic name. These source snapshots were not edited as part of this reconciliation.

## Known limits

- Star Chart map edges are not treated as mission unlock rules, so the application does not calculate every node-to-node route. It tracks the supported node, planet/region, junction, quest, and activity gates.
- Full-repository ESLint still reports its recorded baseline of 1,870 errors and 37 warnings; focused ESLint for the changed content and quest files passes. The changed files introduced no additional lint errors.
- Strict external-data validation still finds 13 `NaN` drop chances in `all.slim.json` and one missing `relicName` in `relics.json`; 21/23 drop-data files pass. These upstream raw data records were not altered here.
- The external-data updater's GitHub tree API check was unavailable in the earlier refresh attempt. The committed external snapshots are pinned and dated November 8, after the latest release reviewed here; no external item data changed for this quest-only correction.
- The current Eris Mortem page identifies it as the final part of Prologue to Tau. No unreleased or unnamed chapter is represented in the checklist.
