# Tenno-Hub and Underframe comparison

Research checkpoint: 2026-11-18. This comparison records verifiable product and architecture differences; it does not claim general numerical superiority from one paired fixture.

## Evidence and limits

- The live [Underframe site](https://www.underframe.site/) was reviewed through its current indexed UI and featured-build pages. Its visible controls include weapon/build editing, share links, target and external-buff configuration, a simulation calculator, Auto Build, Riven tools, and Incarnon options. A saved Braton Prime fixture was also opened in Codex's in-app browser and its target/result controls were click-tested with rendered captures; broader browser interaction coverage remains open.
- The public [Underframe Desktop repository](https://github.com/NevermindNilas/underframe-desktop/tree/fe38d07f3515a995a068015314ad85acc65bef61) was inspected at commit `fe38d07f3515a995a068015314ad85acc65bef61` (repository last updated 2026-10-25). Relevant sources include its [README](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/README.md), [Auto Build implementation](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/shared/auto-build.js), [worker](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/renderer/auto-build.worker.js), and [Auto Build port notes](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/docs/port-auto-build.md).
- The Desktop repository declares `AGPL-3.0-only` for its public application code. Its README and NOTICE identify `core/` as a private submodule containing the damage engine and game data. This review uses public behavior and documentation only; it does not copy code or rely on the private engine.

## Auto Build objective from public source (2026-11-18)

The latest public [Underframe Desktop repository commit](https://github.com/NevermindNilas/underframe-desktop/commit/fe38d07f3515a995a068015314ad85acc65bef61) is current as of this review. Its [Auto Build port spec](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/docs/port-auto-build.md#0-summary) describes the reviewed `underframe.site` build (staticVersion `1792684257`) and states that default Auto Build selection maximizes mean `avgDps` over seeded five-second simulations. “Build for Raw Damage” and “Build for Status Damage” select alternate metrics.

The source confirms the settings and seed behavior: [`metricOf`](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/shared/auto-build-settings.js) defaults to `avgDps`; [`runsFor`](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/shared/auto-build-settings.js) returns three samples at five seconds with Sample Size Multiplier 3; [`runAutoBuild`](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/shared/auto-build.js) uses seeds 1…N when Luck Averaged is enabled. The Cedo capture's final refinement used 200 samples. The UI readout path separately scores eight seeded runs ([`poolScorer`](https://github.com/NevermindNilas/underframe-desktop/blob/fe38d07f3515a995a068015314ad85acc65bef61/src/renderer/auto-build-job.js)). The README confirms the simulation engine and game data live in a private `core/` submodule.

The Cedo and Lex Auto Build captures therefore used Underframe's mean-`avgDps` search objective. Tenno-Hub's paired optimizer runs used finite Expected TTK, so rescoring both lists through Tenno-Hub gives a common-model comparison, not optimizer-objective parity. Underframe's public search source is available, but the private damage core prevents independently running that simulator here. Continue to report those comparisons with the objective boundary explicit.

## Practical findings

1. Underframe's strongest observable advantages are its broad configuration surface, community build library, Riven workflow, extensive target controls, and multi-target layout. Tenno-Hub's strongest current advantages are its integration with owned progression data, Wiki-linked mechanic explanations, visible scoring boundaries, and explicit finite encounter modeling.
2. Both optimizers use candidate search and refinement. Underframe's public Auto Build source documents a staged heuristic with local swaps and default mean `avgDps` ranking over seeded five-second simulations; Luck Averaged uses deterministic seeds. Tenno-Hub uses beam search and finite-score refinement with goals such as Expected TTK. The existing common-model rescores do not align those search objectives. Tenno-Hub's current tests compare bounded candidate pools against exhaustive legal builds and solver shortlists, while its own work log keeps full-catalog global quality open.
3. The public Desktop source documents worker isolation and reproducible seeded simulations. Its private core prevents independent audit of the final damage engine, so an observed numerical match would be evidence for that scenario rather than proof that either model is generally correct.
4. The next useful optimizer comparison is a reproducible paired corpus: same weapon variant and attack, mod/Arcane ranks, Forma/Catalyst, Incarnon choices, target defenses, external buffs, and conditional state. Compare build legality, objective value, per-run latency, and the actual selected setup. Record cases where assumptions cannot be aligned.
5. Braton Prime and Torid fixtures are now documented above. They remain two individual cases using different native simulators; a broader paired corpus must verify the actual Underframe Auto Build output across several weapon categories, objectives, Arcane/conditional settings, target profiles, and repeat counts before general quality claims.

## Broken War melee capture and fixed-window objective comparison (2026-11-18)

The integrated in-app browser created `/Codex-Matched-Corpus-Broken-War` with Broken War / Melee / Normal Attack against Grineer at 100,000 Health / 3,000 Armor, zero Shields/Overguard, no headshots, external statuses/buffs off, Catalyst on, and initial combo 0. Underframe used Lone Vengeance (Forward), a five-second simulation, 28 CPU cores, GPU off, sample multiplier 3, final refinement with 200 samples, Luck Averaged, Elemental Candidates, Cost Control, and a three-Forma maximum.

Three Auto Build runs returned the same eight mods: Primed Fever Strike R10, Primed Pressure Point R10, Voltaic Strike R3, Galvanized Steel R10, Condition Overload R5, Berserker Fury R5, Primed Smite Grineer R10, and Volcanic Edge R3. The first output was −32/60 with zero Forma. Auto Polarize made it legal at 5/60 with two Forma, and the next two runs retained the list. Three native Luck Averaged reads repeated at 45,286 DPS / 2.30 s; one standard Calculate DPS sample showed 57,385 DPS / 1.74 s.

The prior Tenno-Hub Expected TTK comparison scored the captured list at 12.0 s / 8,333.3 expected DPS and a legal three-Forma build at 8.0 s / 12,500 expected DPS (277 candidates). That evaluator treats the attack as a generic Normal Attack and omits Lone Vengeance's hit sequence, forced-proc timing, and evolving combo.

After source review confirmed Underframe's default Auto Build metric is mean `avgDps` across seeded five-second runs, Tenno-Hub added a deterministic single-target `5s Avg DPS` objective. The reproducible runner `scripts/compareUnderframeFixedWindowDps.ts --runs=3` applies that same Tenno-Hub scorer to captured Cedo, Lex Prime, and Broken War builds and reoptimizes each fixture. Scores were 14,638.7 → 20,000.0 DPS for Cedo, 8,568.5 → 20,000.0 for Lex Prime, and 4,296.2 → 7,068.7 for Broken War. All three optimizer runs per fixture returned the same list and score; all optimized lists passed Tenno-Hub's modeled capacity checks under the shared three-Forma cap. Full scores, attack counts, capacities, and durations are in `BUILD_PLANNER_BENCHMARK.md`.

The new score uses applied damage divided by five over `[0,5s)`, clips overkill, excludes events at 5 seconds, starts on-kill stacks at zero, and does not reset the target. It is deterministic and mean-field, not Underframe's private seeded stochastic damage engine. The Cedo/Lex score reaches the `target health / 5s` ceiling, so the listed TTK is diagnostic and does not affect ties. The Broken War row still omits stance/combo history. These are same-objective comparisons within Tenno-Hub's model, not engine parity, global optimizer optimality, or live-game validation. After Pages run [#254](https://github.com/Appl3Tree/Tenno-Hub/actions/runs/44843909526), the integrated browser verified the production `5s Avg DPS` selector, its assumptions, a legal 57/60 Cedo build, and the result explanation at 20,000 DPS / 4.81 s diagnostic TTK. The local preview remained unreachable; exact one-mod neighborhood audits, broader objective-matched coverage, and live-game validation remain open.
